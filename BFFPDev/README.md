# 🚀 Backend from First Principles

> **From API Builder → Backend Engineer**

A structured learning journey based on **Sriniously's Backend from First Principles** playlist.

The goal is not just to memorize frameworks, libraries, or syntax.

The goal is to understand **how backend systems actually work** — from HTTP and routing to databases, caching, queues, security, scalability, observability, testing, and DevOps.

---

## 🎯 The Mission

Build a strong foundation in backend engineering by understanding systems from **FIRST PRINCIPLES**.

The goal is to gradually move from:

```text
"I can build an API."
        ↓
"I understand how an API works."
        ↓
"I understand what happens behind the API."
        ↓
"I can design, debug, scale and secure backend systems."
        ↓
"I THINK LIKE A BACKEND ENGINEER."
